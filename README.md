# MSA Cloud Management System

## 📚 Course
Cloud Computing

## 📦 Project Description
The **Cloud Management System** is a user-friendly command-line tool designed to help users manage virtual machines and containers using **QEMU** and **Docker**. This project demonstrates core virtualization and containerization concepts by providing interactive features to create and manage virtual disks, VMs, Dockerfiles, images, and containers.

## 🚀 Features

- 🔹 **Create Virtual Disk** (Specify type, format, and size)
- 🔹 **Create Virtual Machines** with configurable CPU, memory, and disk
- 🔹 **Generate Dockerfiles** with custom content
- 🔹 **Build Docker Images** from Dockerfiles
- 🔹 **List Docker Images** on the system
- 🔹 **List Running Containers**
- 🔹 **Stop Containers**
- 🔹 **Search Docker Images Locally**
- 🔹 **Search and Pull Docker Images from DockerHub**

## 🛠️ Technologies Used

- **QEMU** – Virtual machine management
- **Docker** – Containerization platform

- **Git** – Version control
